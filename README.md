The final goal of this project is to develop a game with the use of AI image recognition skills.
Give (or generated) an image the programmer will check if the AI is capable of locating all the matching objects and making a list.
By choosing some of them the user is then required to guess where the specific object is coming from the image from the shape or shadow of it.
Increasing difficulties is coming from images with similar and many objects on it.
More idea are welcome along the development.
